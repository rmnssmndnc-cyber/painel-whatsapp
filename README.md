# Painel WhatsApp

Aplicativo para Windows com contatos, mensagens livres, imagens e PDFs.

## Versão publicada

[Baixar versão 2.2.1](pacotes/Painel_WhatsApp_2_2_1.zip)

Corrige o rótulo do endereço de publicação na janela Atualizações. O ZIP inclui código-fonte e instruções. Requer o ambiente Python e Playwright já instalado no projeto.

## Atualizar pelo painel

A partir da versão 2.2.0, abra **Atualizações** e configure a fonte:

```
https://raw.githubusercontent.com/rmnssmndnc-cyber/painel-whatsapp/main/atualizacoes.json
```

Clique em **Verificar e atualizar**. A versão mais recente será instalada e o painel reaberto. Novas versões precisam ser desenvolvidas, testadas e publicadas; o programa não cria atualizações sozinho.

Contatos, campanhas, anexos, sessão e histórico ficam no computador. Não envie a pasta `dados` para este repositório.

A instalação 2.2.0 → 2.2.1 foi validada em cópia temporária, preservando dados e backup. A reabertura no Windows ainda precisa de validação no computador do usuário.
