# Painel WhatsApp

Aplicativo para Windows com contatos, mensagens livres, imagens e PDFs.

## Versão publicada

[Baixar versão 2.2.0](pacotes/Painel_WhatsApp_2_2.zip)

O ZIP inclui código-fonte e instruções. Requer o ambiente Python e Playwright já instalado no projeto.

## Atualizações

No painel 2.2.0, abra **Atualizações** e configure a fonte:

```
https://raw.githubusercontent.com/rmnssmndnc-cyber/painel-whatsapp/main/atualizacoes.json
```

**Verificar e atualizar** consulta a versão publicada e instala quando for mais recente. Novas versões precisam ser desenvolvidas, testadas e publicadas; o programa não cria atualizações sozinho.

Contatos, campanhas, anexos, sessão e histórico ficam no computador. Não envie a pasta `dados` para este repositório.

Validação local: 32 testes sem envio real. A instalação e reinicialização no Windows ainda precisam de validação no ambiente do usuário.
